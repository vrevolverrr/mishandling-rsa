Mishandling RSA

A simple project demonstrating Fermat's factorisation on RSA modulus for close primes (FIPS 186-5) and a simulation of Lenstra's attack (1996) involving a insufficient hardening of RSA-CRT faults which leak private keys via GCD(difference of the verified signature and original message, RSA modulus).

Developed as part of NTU SC4010 Applied Cryptography coursework.
